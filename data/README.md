# Dataset

The dataset used for this project is the **Online Retail** dataset from the UCI Machine Learning Repository.

Because the dataset is too large to include in this GitHub repository, please download it directly from the source.

## Download

https://archive.ics.uci.edu/ml/datasets/Online+Retail

## Setup

1. Download the dataset.
2. Rename the file to:

```
retail_data.csv
```

3. Place it inside the `data` folder:

```
Customer-Behavior-Analysis/
└── data/
    └── retail_data.csv
```

The project should now run without any additional changes.
